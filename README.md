## Цель

Реализовать и сравнить несколько подходов к рекомендациям — от классической коллаборативной фильтрации до нейросетевых моделей на домене музыкальных треков. Сравнение ведётся по качеству рекомендаций, трудозатратам на реализацию и поддержку, а также по масштабируемости.

## Задачи

### Данные и аналитика
- Собрать и проанализировать подходящие данные (например, есть датасет Yambda от Яндекс Музыки).
- Построить гистограмму популярности жанров (число прослушиваний / минуты прослушивания) за выбранный период.
- Построить топ-N треков внутри каждого жанра за выбранный период.

### ML
- Рекомендательная система на основе коллаборативной фильтрации (матричные факторизации по разреженной матрице «пользователь — трек»).
- Классификация жанра трека (или вероятностей принадлежности к жанрам), в том числе по аудиопризнакам.
- Кластеризация пользователей по музыкальным предпочтениям.
- Двухуровневая архитектура (генерация кандидатов + ранжирование).

### DL
- Рекомендательная система на основе нейросетевого подхода, трансформеры для кандидатогенерации и фич для ранжирования
- Улучшение качества ML-задач за счёт DL (например, эмбеддинги треков из аудио).

### Дополнительно
- Повышение разнообразия, новизны и «внезапности» (serendipity) рекомендаций.
- Использование внешних признаков пользователей и треков.
- Если сумеем, то было бы интересно попробовать имплементировать End-to-End нейросетевой подход

## Подходы
- **Статистические методы** - например, рекомендовать популярные треки или треки понравившегося артиста. Не трогая ML
- **Коллаборативная фильтрация** — восстановление неизвестных оценок по известным взаимодействиям пользователей с треками.
- **Двухуровневая архитектура** - выделить как минимум две отдельные фазы (кандидатогенерация и ранжирование) и комбинировать их наиболее выгодным способом
- **Content-based** — построение векторов треков по аудиофайлу (жанр, настроение и другие характеристики звучания).
- **Гибридные модели** — сочетание коллаборативных и контентных сигналов.
- **Нейросетевые подходы** - изучить и применить DL подходы для кандидатогенерации/ранжирования.
